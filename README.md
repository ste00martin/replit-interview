# Expo React Native Template

Hit Run to start the app server.

This will load the web version in the Webview pane. You can resize the Webview pane to test on different screen sizes, or open in a new browser window via New tab button.

Edits you make to files will auto-refresh the app. If the server stops for any reason, you can restart via the Run button.

### Run on device

Download the Expo GO app on your iOS device (Android not supported yet).

Scan the QR code in the Console pane using the iOS camera or Expo GO app to load the app.

### Set up

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/create-pages/).

The code in the **app-example** directory gives you an example of using tabs and the included components. Using these components is optional.
